### 🌀 Maze Generator & Solver

A visual, interactive maze generator and solver built from scratch with vanilla JavaScript.

**What it does:**
- **Generates** perfect mazes using the **Recursive Backtracker (Randomized DFS)** algorithm
- **Solves** them with **Breadth-First Search (BFS)** to find the shortest path
- Watch both algorithms execute step-by-step in real-time on an HTML5 Canvas

**Built with:** JavaScript, HTML5 Canvas, CSS  
**Concepts:** Graph traversal, stack/queue logic, backtracking, shortest path

🔗 [Live Demo]( https://amninajiha.github.io/maze/) · [Repository](https://github.com/amninajiha/maze)

### 👁️ Raycaster 3D Engine

A pseudo-3D rendering engine inspired by classic 90s FPS games, built entirely in vanilla JavaScript.

**What it does:**
- Renders a 3D perspective view using **DDA ray casting** with perpendicular distance correction
- Handles **vector math, trigonometry, and projection** without any 3D libraries
- Features **grid-based sliding collision detection** for smooth movement
- Controls: WASD to move, Arrow Keys / Mouse to look, Shift to run

**Built with:** JavaScript, HTML5 Canvas  
**Concepts:** Ray casting, computational geometry, collision detection, game loop

🔗 [Live Demo](https://amninajiha23.github.io/raycaster/) · [Repository](https://github.com/amninajiha23/raycaster)
